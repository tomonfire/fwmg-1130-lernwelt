# Sicherheit

Die App ist rein statisch, hat keine Anmeldung und sendet keine Daten an einen Server. Der Lernstand bleibt im Browser des Geräts.

- Keine API-Schlüssel, Passwörter oder personenbezogenen Daten in das Repository schreiben.
- Eine KI-Anbindung darf nur über ein Backend erfolgen, das den Schlüssel verwahrt.
- Probleme bitte nicht öffentlich als Issue melden, sondern vertraulich über **Security → Report a vulnerability** im Repository. Das ist der vertrauliche Weg über GitHub, ohne dass eine E-Mail-Adresse nötig ist.
