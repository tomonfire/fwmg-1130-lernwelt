# Roadmap

Reihenfolge ist ein Vorschlag, nach Nutzen und Aufwand.

## Als Nächstes
- [x] **Lernstand sichern:** Export und Import als Datei, damit er beim Gerätewechsel nicht verloren geht.
- [x] **Name** beim ersten Start als Pflichtfeld.
- [x] **Fragen auslagern:** Fragen aus den HTML-Dateien in JSON-Dateien (`app/data/`), Pflege ohne Code.
- [x] **Automatische Browser-Tests:** Startseite, Trainer, Offline-Betrieb (Playwright) in der CI.
- [ ] Browser-Tests erweitern: Einstellungen in der Übersicht, Prüfungsablauf, Lernstand bleibt nach Update erhalten.
- [ ] **Branch-Schutz** für `main` aktivieren (öffentliches Repository, siehe [REPOSITORY.md](REPOSITORY.md)).

## Danach
- [ ] Lizenz und Rechte an den Fragen klären (Lernkompass IdF NRW).
- [ ] Eigene Fragen hinzufügen und teilen (Einheit, Löschzug).
- [ ] KI-Rückmeldung im Befehlstrainer über ein Backend.
- [ ] Weitere Trainer, z. B. Funk, Einsatzstellenhygiene, Atemschutz.
- [ ] Barrierefreiheit prüfen (Screenreader, Kontrast, Schriftgröße).

## Ideen
- Lernstand pro Person mit gemeinsamer Auswertung für Ausbilder.
- Prüfungstermine und Erinnerungen.
- Englische Oberfläche.
